# Instructions

Create a **conference day** web application for the [2015 React conference](https://conf2015.reactjs.org/schedule.html).

Your goal is to:

- Use a modern React stack.
- Use the existing data from the website. Feel free to augment with additional data as needed.
- The website should optimized for attendees. (No need for a checkout flow).

We hope you'll take the extra time to pack in some features that exceed the project definition and embed some of your opinions on user experience. We will judge results based on the depth and quality of the outcome. You are expected (and encouraged!) to use AI tools to complete this task.

In the in-person phase of the interview, we’ll ask you about the code, ask questions about the product decisions you’ve made, and implement a small new feature (without AI assistance).
